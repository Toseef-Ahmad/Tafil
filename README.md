# TAFIL

**The project command center for developers**

Plan projects, write docs, experiment with code, and manage everything in one desktop app — working alongside your IDE.

[⬇️ Download TAFIL](https://github.com/Toseef-Ahmad/Tafil/releases) • [🌐 Website](https://tafil.app)

</div>

---

## Why TAFIL?

- An all-in-one workspace for developers 🧠  
- Manage projects without opening an IDE 📁  
- Code playground for quick experiments ⚡  
- Markdown notes & project documentation 📝  
- Visual planning with boards & diagrams 📐  
- Works fully offline — your data stays local 🔒
