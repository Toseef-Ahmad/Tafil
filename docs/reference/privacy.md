# Privacy (Local‑First)

Tafil is a **local-first** app.

- **Works fully offline**: no cloud required.
- **No accounts**: you don’t need to sign in.
- **No tracking**: Tafil does not include analytics or behavior tracking by default.
- **Your projects stay local**: project paths, run commands, logs, notes, and blueprints are stored on your machine.

If you connect to servers using SSH, that connection is initiated by you. Tafil does not proxy or relay your traffic through third-party servers.
